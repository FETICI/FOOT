MISE À JOUR ICÔNE OSCC — V_CLAUDE

Ce ZIP contient uniquement les fichiers à ajouter/remplacer dans le dépôt GitHub actuel.
Il ne remplace PAS les autres fichiers de V_Claude.

À la racine du dépôt GitHub :
- remplacer public/admin.html
- remplacer public/index.html
- ajouter public/apple-touch-icon.png
- ajouter public/oscc-icon-512.png

Après le redéploiement Railway :
1. Sur l’iPhone, supprimer l’ancien raccourci de l’écran d’accueil.
2. Ouvrir de nouveau la page Admin dans Safari.
3. Partager > Sur l’écran d’accueil.
4. L’icône OSCC doit maintenant apparaître.

Nom iOS défini : OSCC.
